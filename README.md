# Surface Type Classification and Roughness Detection on ESP32-S3

This repository implements real-time surface type classification and roughness detection on ESP32-S3.

## Features
- Surface type classification at around 5 Hz
- Roughness detection at around 100 Hz
- Parallel processing pipeline
- RGB image capture and processing
- BLE connectivity for data transmission to sensBox:bike app

## Hardware
- ESP32-S3 microcontroller
- Camera module OV2640
- ICM20948 IMU
